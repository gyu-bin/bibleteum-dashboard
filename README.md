# 바이블틈 통계 대시보드

- 앱 사용 통계는 Supabase의 공개 집계에서 최근 7·30·90일 수치를 불러옵니다. 통계 전송에 동의한 설치만 포함합니다.
- 스토어 통계는 Google Play Console과 App Store Connect에서 확인한 집계를 `store-metrics.json`에 보관합니다. 갱신할 때 확인일, 조회 기간, 수치의 집계일을 함께 확인합니다. 확인할 수 없는 지표의 값은 `null`로 두고 상태를 적습니다.

이 저장소에는 웹 화면과 공개용 스토어 합계만 둡니다. 앱의 원본 이벤트, 설치 식별자와 운영용 접근 키는 포함하지 않습니다.
